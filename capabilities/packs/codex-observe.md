# codex.observe — R0 能力说明

状态：candidate only。用途是为 `codex_observe` 形成已授权范围内的只读观察计划；它不是 Codex 控制器、任务运行器、会话恢复器或权限来源。

## 输入与边界

- 观察对象必须由用户或已核真的治理状态明确指定；不使用“最近”“默认”或猜测身份扩大范围。
- 区分配置、进程/会话存在、队列投递、任务运行、终态回执和业务接受；一个层级的证据不能替代另一个层级。
- 当前权限、可访问性和证据新鲜度必须显式报告；无法实读时为 `UNKNOWN`。

## R0 任务规则

1. 只提出最小、无副作用的状态读取计划，并为每项读取标明目标、来源和停止条件。
2. 队列命令退出码 0 仅表示提交尝试，不证明接收、执行或完成。
3. 发现冲突 writer、身份漂移、敏感信息或需要恢复型动作时立即停止。
4. 输出只包含观察事实、证据局限与下一安全建议，不生成执行令。

## 明确禁止

不得创建、排队、唤醒、恢复、归档或终止 Codex 任务，不得读取无关会话或秘密，不得调用 MCP，不得改配置或安全设置。本说明和目录命中均不构成工具调用授权，也不提供执行器。
