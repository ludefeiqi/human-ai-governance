# 候选与真实验收的不同范围

静态：双manifest版本/身份、来源锁、全部本地参考可达、没有预绑定项目或放宽权限。
合成：两个项目一项403；源码已核但正文缺失；ledger覆盖旧Issue；未知运行态；下级注入；HEAD漂移；不同窗口不重复派工；静态预检不冒充批准。
真实R0：在本窗口用授权GitHub核policy Tag→Commit、原始Manifest和GENESIS、最新目录，单个现存项目可核范围才报告覆盖。
真实冷启动：批准安装后开一个独立普通Chat，完整读取本版Skill/来源锁、运行确实可用的校验工具并读实际账本；不需要为了形式强制再开Work。无新窗口只能COLD_START_PENDING。
双项目验收：必须独立批准并登记第二个真实项目，不用合成样本冒充。业务派工/移交仍未解锁；不得为本验收重做认证或生产动作。
